# Support

Use [GitHub Issues](https://github.com/NVIDIA/scada-client/issues) for
non-security build problems, bugs and feature requests. Include the commit,
OS, kernel, compiler, CMake, CUDA, CCCL, GPU architecture, build options,
installation method and minimal reproduction. Runtime reports should identify
the server version and relevant logs with sensitive information removed.

This project is under development. No response-time, production-support or
long-term compatibility guarantee is provided. Report vulnerabilities privately
under [SECURITY.md](SECURITY.md).
